# Bundle Monetization Plan

Last updated: 2026-07-04

## Primary Offer

Launch `Strange Systems Starter Pair` as the first paid product.

- Deliverable: `products/strange-systems-starter-pair/Strange-Systems-Starter-Pair.zip`
- Contents: nested Beef Ritual and Cobalt Chapel Theme Pack ZIPs, buyer README, usage guide, license, support file, listing copy, tags, and preview assets.
- Positioning: a ready-to-use brand color system starter pair for websites, portals, launch pages, dashboards, and digital products.

## Offer Ladder

- Individual kits: $9-$12 each.
- Starter Pair launch price: $17-$19.
- Starter Pair standard price after validation: $24.
- Future three-pack or seasonal bundle: $29-$39 once at least one listing proves demand.

Keep the bundle as the lead product because it has a stronger perceived value than a single palette and the current package is still small enough for direct digital delivery.

## Launch Channel

Start with one marketplace listing plus one direct checkout mirror.

- Marketplace listing: upload the bundle ZIP and use `shop-listing.md`, `tags.txt`, and `marketplace-preview/` from the product folder.
- Direct checkout mirror: list the same bundle with matching price, then use coupons for controlled testing.
- Do not create more SKUs until the first bundle has traffic data.

## Listing Setup

- Title: use the product name plus clear buyer terms such as website color kit, brand palette, and design tokens.
- Cover image: export `marketplace-preview/marketplace-cover.svg` to PNG/JPG if the target marketplace prefers raster previews.
- Preview carousel: include the bundle comparison image, both palette cards, both swatch strips, and one screenshot showing included file formats.
- Description: paste from `shop-listing.md`, then add a short note that this is an instant digital download.
- Tags: start from `tags.txt`; replace any low-performing terms after the first traffic review.
- File: upload only the current ZIP named in `products/RELEASE_QA.md`.

## First 14 Days

- Day 1: publish the bundle at $17-$19 and verify the buyer download opens cleanly.
- Days 2-3: post three short demos: the palette card, the token files, and a before/after website mockup.
- Day 7: review visits, favorites, carts, and sales; change the first preview image if click-through is weak.
- Day 14: move to $24 standard price if there is at least one sale or meaningful cart activity.

## Decision Rules

- If there are fewer than 100 listing views, do not judge the product yet; improve traffic.
- If there are 100+ views and no favorites, revise the thumbnail and title.
- If there are favorites but no carts, revise price or first paragraph.
- If there are carts but no sales, add a launch coupon or strengthen the included-files preview.
- If support questions repeat, update `USAGE.txt` and regenerate the ZIP before the next upload.

## Next Product

After the first sale or a clear traffic signal, build the next bundle around a narrower buyer keyword:

- SaaS dashboard color kits.
- Gothic brand palette packs.
- Accessible website token bundles.
- Launch page color systems.

Use the same Product Forge path so every new SKU includes the same README, usage, license, support, listing, tags, and preview structure.
