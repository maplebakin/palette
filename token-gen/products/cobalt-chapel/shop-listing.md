## Short Description

A sacred-tech blue website and brand color kit with CSS variables, JSON tokens, Figma/Penpot files, LibreOffice palette support, and SVG previews.

## Long Description

Cobalt Chapel is a complete Apocapalette color kit built around saturated cobalt, chapel-dark navy surfaces, cool ivory text, teal patina accents, and restrained candlelight gold. It is designed for makers who want a blue system with atmosphere and authority instead of another flat corporate navy palette.

The kit includes CSS variables for web projects, structured JSON tokens, Figma-friendly token JSON, Penpot-compatible tokens, a LibreOffice/OpenOffice .soc palette, usage notes, license terms, and preview SVGs for quick visual reference. Use it as a starting point for dashboards, developer tools, AI interfaces, finance concepts, portfolio sites, gallery pages, music/nightlife brands, or dramatic product prototypes.

Theme direction: Cobalt Palette, Blue UI, Sacred Tech, Premium UI, SaaS UI, Dashboard Design, AI Tools, Developer Tools.

Includes confirmed reviewed light, dark, pop modes only. Missing modes are not regenerated during export. Includes CSS variables, JSON tokens, Figma/Penpot files, LibreOffice palettes, previews, marketplace preview artwork, and usage notes.
Use the dark, light, and pop mode folders for mode-specific implementation, the combined files for all-mode references, and the preview assets for quick QA or shop listing visuals.

## Mode Structure

- Includes confirmed reviewed light, dark, pop modes only. Missing modes are not regenerated during export.
- This is a multi-mode kit with separate Light, Dark, and Pop mode folders. Each mode folder contains matching CSS, JSON, Figma, Penpot, LibreOffice/OpenOffice, and preview files for that mode.
- `combined/tokens.all-modes.json` and `combined/css/variables.all-modes.css` provide all included modes in one reference layer.
